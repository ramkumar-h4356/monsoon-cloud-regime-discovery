# Monsoon Cloud-Regime Discovery

Exploratory study of cloud-feature groupings over India during the established-monsoon period, 2010–2021.

## Study Scope

- Seasonal window: 15 July–13 August (30 days/year).
- Spatial domain: 6.5–37.5°N, 68.5–97.5°E.
- Grid: 32 × 30 cells.
- Dataset: CERES SYN1deg.
- Methods: PCA, t-SNE, K-means, stability analysis, spatial and temporal analysis, external rainfall association.

## Scientific Scope

Clusters are exploratory statistical groupings, not conclusively validated meteorological regimes. Rainfall is used only for external observational association and is not a clustering input.
